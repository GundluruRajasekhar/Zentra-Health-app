# Zentra Health
Offline multi-agent health app. Open `index.html` in a browser; no setup or API keys.
## Demo script (2 min)
1. Dashboard: click "Simulate wearable data" and watch the risk score and recommendations change.
2. Health Twin: view the 7-day BP forecast, then press "Simulate fall" for the escalation flow.
3. Agent Collaboration: press "Run agent cycle".
4. Reports & Meds: analyze the sample report.
5. Doctor & Coach: ask "Is my BP okay?" or use the voice coach.
## Honest limitations
Rule-based logic, simulated wearable data, no clinical validation. Not medical advice.
## Roadmap
Web Bluetooth / Health Connect wearables, on-device OCR (Tesseract.js), clinician-reviewed rules, pilot study.
